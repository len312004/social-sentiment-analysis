# Social Sentiment Analysis

A web-based dashboard for analyzing and visualizing social media sentiment, engagement, and trending topics.

This project was developed to explore how social media data can be presented through an interactive dashboard, allowing users to view sentiment distributions, engagement metrics, hashtag trends, and other social media insights.

## Features

- Sentiment overview and visualization
- Positive, neutral, and negative sentiment categories
- Social media engagement metrics
- Trending hashtag monitoring
- Interactive charts and graphs
- Word cloud visualization
- Platform overview
- Search and filtering functionality
- Responsive dashboard interface

## Technologies Used

- React – Frontend user interface
- TypeScript – Application development and type safety
- Vite – Development and build tool
- Tailwind CSS – User interface styling
- Chart.js – Data visualization
- Recharts – Dashboard charts and graphs
- Framer Motion – Interface animations
- React Router – Application navigation
- Lucide React– Interface icons
- Git & GitHub – Version control and project repository
